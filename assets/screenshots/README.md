# Screenshots

Marketplace screenshots. Conventions:

- PNG, minimum 1000px wide (Anthropic's hard requirement)
- App response only — no prompt text overlaid on the image
- Curated demo workspace only — never real customer or workspace names
- Each screenshot is paired with the example prompt that produced it in
  [`PROMPTS.md`](./PROMPTS.md), so reviewers see both

Filename pattern: `NN-short-description.png` (numbered for ordering).
